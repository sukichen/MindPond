# 架构与边界

MindPond 是本地优先的记忆服务，通过 TypeScript SDK、HTTP 和 MCP 提供同一套持久状态与校验。它不内置语义整理模型，也不保管宿主模型凭证。

SQLite 保存记忆正文、空间成员、无向关联及其场景依据、来源版本、画像支持链、修订、动作日志和可恢复工作队列。多进程可以共享同一个数据库；事务协调、租约及乐观版本检查用于防止并发覆盖和过期提交。共享数据库仍需可靠的本地文件锁，不建议通过网络文件系统共享 SQLite。

Domain 决定归属与生命周期：session 只对宿主绑定的当前会话可见，personal 用于长期个人知识，team 的语义写入必须有真实用户请求产生的宿主授权。Space、memoryType 和自定义 dimension 决定各自的关联网络。共享正文可以在同一域、同一空间拥有多个维度身份，作为维度之间的桥梁；普通关联不跨域、空间或类型。

检索融合正文向量、文本和最多六个锚点入口。多个直接命中并行激活，各路径独立沿关联传播，强度按边权相乘，同一结果保留合适的路径解释。权重与融合分数不是真实性概率，宿主仍需检查来源、新鲜度和原始适用条件。可选模型使用独立向量空间，支持 CPU、可用的 GPU 后端和可选 HNSW；模型缺失或通道失败会显式报告降级。

整理任务交付完整、不可变的材料快照。宿主生成提案，MindPond 预览、校验并原子提交；租约过期和材料变更会拒绝旧提案。去重、整合、综合画像和关联复核保留条件、来源与修订。仅被检索或反复使用不会自动增加事实可信度。

多 agent 协作有独立任务板：依赖、认领、续租、阻塞、提交和验收不直接进入长期知识。MindPond 保存协作状态，宿主承担调度、实际执行、外部副作用幂等与成员授权。拥有同一操作系统文件权限的程序不被 MCP 隔离；此产品也不是完整的敌对租户 SaaS 身份系统。

动作日志和读取回执支持前端展示及维护反馈，不代表系统保存隐藏推理。自动化契约测试不能替代真实模型的语义质量评估。
