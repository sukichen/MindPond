# ADR 0001: MindPond 产品边界与不可破坏语义

- 状态：已接受
- 日期：2026-09-20
- 关联：[架构边界](../architecture.md)、[验证与发布](../releasing.md)

## 背景

MindPond 是独立通用记忆产品。接入方是任意具备工具调用能力的 agent（及具备生命周期扩展能力的宿主）。近期整理故障（预算被重试放大、永久错误重复入队、旧通路绕过协议、后台失败仍报运行中）表明：仅靠提示词约束无法保证边界，必须有程序接口强制执行。本 ADR 固化产品职责边界与语义底线，作为后续所有任务卡（R/O/A/Q/E）的决策依据；与其冲突的实现一律以本 ADR 为准，除非先修订本 ADR。

## 决策

### 1. 各方职责边界

| 层次 | 必须负责 | 不承担 |
| --- | --- | --- |
| MindPond 核心 | 数据、可见范围校验、候选、材料、规则、任务状态、租约、提交、错误、回执、评估 | 保存模型 key；猜测用户真实授权；执行任意宿主代码 |
| MindPond 通用驱动器 | 按协议领取任务、调用宿主注入的模型函数、传递截止时间和取消、提交及恢复 | 绑定 rpbot；强制采用某家模型；另建一套记忆业务状态 |
| 宿主适配器 | 连接配置、可信用户/session 身份、用户授权事件、模型调用接口、可用的生命周期事件、进度展示 | 自行拼整理 SQL、裁剪来源、决定重试规则、发明记忆合并流程 |
| LLM | 基于完整材料判断可复用信息、关联理由、整合或画像，按输出契约给提案 | 改写授权范围、越过租约、把猜测当验证、宣称未提交工作已完成 |

### 2. 接入等级

- **基础接入**：安装工具连接，读取短规则；用户请求时完成搜索、保存和整理。没有后台执行器时，整理暂停后如实显示等待执行者。
- **增强接入**：宿主提供工作开始、里程碑、压缩前、结束和恢复等真实事件；运行通用驱动器，可形成阶段记忆、执行后台整理和补交回执。

不能因 MCP 工具安装成功就宣称支持自动记忆或自动维护。每个客户端的真实版本、规则加载方式、事件能力在接入时核实并记录。

### 3. 不可破坏语义（固定规则）

| 项目 | 固定规则 |
| --- | --- |
| 域 | session 只对当前逻辑会话可见；personal 保存长期知识；team 语义写入必须来自真实用户主动请求。读取遵循已配置身份与域可见范围 |
| 身份 | agentId、hostId、userId、sessionId、runId 含义不同；换 agent 不必换逻辑 session，换 session 不能偷带旧 session 记忆 |
| 空间与维度 | 同一记忆可有多个显式维度，在同一空间内作为维度桥梁；不能借共享正文跨到另一个项目空间 |
| 涟漪 | 多个直接命中是并行种子；实际经过的边逐跳乘权（两个 0.9 边产生 0.81 路径强度）；路径不累加成概率；维度切换本身不新增一跳 |
| 关系 | 语义关联保存理由、发生场景、条件及例外；原始日志走独立证据追溯；画像支持关系不自动变成涟漪边 |
| 跨域 | 私人对团队记忆的引用不产生反向泄漏；不能用整理、画像或锚点绕过 session/team 边界 |
| 锚点 | 一份正文所有位置合计最多 6 个，来自正文依据，不能凑数；正文变更后旧锚点须复核 |
| 整合 | 不把相似当相同；保留有独立价值的细节和来源；"未验证"不能变成"不适用"或"已验证" |
| 协作 | todolist、认领、租约、执行回执属于独立协作状态，只有值得长期复用的结果才进入知识图 |

### 4. 教会宿主的方式

同时依靠提示词与程序接口：提示词指导选择（何时调用、如何选域、怎样写内容、出错怎样修正），核心强制执行边界与状态。提示词不能代替生命周期钩子、进程调度或权限认证。

### 5. 发布门槛

- 核心构建、测试、发布不依赖 rpbot；**完全脱离 rpbot 仍能安装、运行和验收**是核心发布门槛。rpbot 只是消费者、高频试验宿主，只消费协议、提供模型执行与展示。
- 宣称"支持某 agent 自动记忆"必须另有该版本增强模式的证据；宣称"整理/锚点提高效果"必须另有保留集结果。
- 反例固定：多种子独立、同空间维度桥、session/team 反向泄漏以夹具形式固定于 `evals/fixtures/`，基线演进中不得回归。

## 后果

- R03（可信上下文）的实现必须覆盖上表全部读取/写入路径，LLM 自报身份一律无效。
- 旧 weave/L2/duplicates 通路（R04）不得作为绕过上述语义的替代路径。
- 任何任务卡若需突破某条固定规则，必须先修订本 ADR 并在提交说明中引用。
- 协议与提示词由运行时版本声明，生成文档必须与源码一致。
