怎么保存 token，怎样区分多个聊天？

token 只交给宿主 MCP 客户端，由它自动附加认证。配置模板只引用环境变量名称。不要把真实值发给 agent，也不要提交到 Git。环境变量若同时能被 shell 工具读取，就没有实现秘密隔离。

每段聊天领取独立分工，使用自己的工作会话编号。需要严格隔离时，为对应分工签发受限凭据，并在宿主中分别暴露连接；两个聊天都看得到两套连接，就仍然不算隔离。

只有 MCP、看不到本地文档的 agent，可以直接调用 work_bootstrap 和 work_guide_get 学习操作。

协作项目（可选）：复用成员授权，归组多间办公室

一个项目可以有多间任务办公室。项目成员是允许参与的 agent；每间办公室仍需安排具体会话分工。停用项目会撤销这些工位的访问，不改变任何个人或团队记忆权限。个人临时协作可不建项目。
